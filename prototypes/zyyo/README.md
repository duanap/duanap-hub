# Zyyo 多页面 HTML 布局复刻

参考 https://zyyo.net/ 于 2026-10-20 的首页。仅在 `prototypes/zyyo/` 中新增静态页面，没有接入 Hub 应用、数据库或生产发布。

- 双击 `index.html` 可预览；所有字体、图片和样式已保存在 `assets/`。
- 运行 `node prototypes/zyyo/serve.mjs`，访问 http://127.0.0.1:1027/ 。
- `preview.html` 可切换页面，以及 1440、1280、390 像素画布。
- `styles.css` 保留参考站的公开编译样式；`replica.css`、`replica.js` 是独立补充的浏览器代码。HTML 保留参考文案和 SVG，便于核对布局。
- 已补齐 Home、Blog、Photos、Notes、Links、About、Tags、4 页文章列表、31 个标签筛选页及 27 个文章详情示例，共 68 个 HTML 页面。站内导航、文章、标签和分页均在本地跳转；友链与项目外链保留原目标。
- 支持文章搜索、随记搜索/随机排序/展开、相册打开/返回/图片灯箱、友链动态搜索/作者和日期筛选、详情目录与章节定位，以及主题切换、手机菜单、首页动效、实时钟、本地音乐试听。
- `pages-manifest.json` 记录页面和原路径映射；`data.js` 是浏览器本地使用的示例数据。原 `/blog` 等路径也可通过静态预览服务访问。
- 长篇文章和随记正文使用本地编写的示例内容，供核对排版；未批量复制原站文章。相册使用每组 4 张封面素材演示内页与灯箱，没有下载原站全部照片。友链动态使用本地示例标题和摘要，时间与作者来自参考快照，不是实时订阅。
- 两个无法获取的头像素材使用本地备用图，具体记录见 `pages-manifest.json`。
- 原站音乐搜索、留言、赞助及植物生成服务未接入；音乐改用用户主动选择的本地文件，植物保留参考图形并提供固定花朵切换。桌面拖动使用卡片交换，未复现原站的挤压重排算法。
- 后续确认视觉后，再将文案及入口替换为 duanap 内容，并拆入现有 Next.js 组件及 Studio 配置。

## 本次验证

- 68 个页面及对应原路径共 138 次 HTTP 检查均返回 200；本地资源、站内链接和章节锚点无缺失。
- 浏览器验证了文章搜索、分页、标签、详情目录、随记排序/展开/搜索、相册灯箱翻页、友链日期/作者筛选，以及 390 像素画布中的菜单跨页导航。
- `pages.js`、`replica.js`、`serve.mjs` 语法检查通过；代表性页面未发现浏览器控制台错误。
- 修改仅在 `prototypes/zyyo/`，未接入主站应用、数据库、生产配置或第三方写入接口。
