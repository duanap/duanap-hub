### 回退限制

故障回退先收敛相关功能开关并查询未决回执，保留已部署的 WordPress 用户事务保护、用户/UID/社交绑定/业务事件和积分账本。关闭 Bridge 统一签到会恢复原生处理；若冻结全部签到，须另关原生签到。按受控流程撤销普通用户会话和专用令牌，回退后用户需重新授权。

不得恢复旧积分/余额数据库、旧管理员密码或旧 Redis 用户缓存前缀；必须保留当前已确认可用的 Studio 新密码。旧发布与私有备份留存不等于可覆盖当前业务数据；回退脚本仅通过只读演练，备份恢复仅在新库验证。后续操作须以 [生产记录](P2-PRODUCTION-2026-10-16.md) 和 [回退顺序](P2-ROLLOUT-2026-10-15.md#上线与回退顺序) 为依据，并服从上述当前限制。

## 使用限制

- 首页预览展示已经保存的公开内容；保存后刷新预览。Markdown 编辑器支持当前草稿预览。
- 图片每张最多 5 MiB，GIF 使用首帧；最多 1000 个媒体文件。在线备份预检原始文件总计不超过 80 MiB，解压 JSON 上限 128 MiB。
- 一个 `HUB_DATA_DIR` 只允许一个 Node 应用进程；恢复和版本切换需要停机。断电/强杀后的不完整恢复需检查维护锁及暂存/回滚目录，不能直接删锁后启动。
- 默认 OG 图片使用内置字体和 ASCII 品牌文字，避免中文字体触发外部下载；页面中文标题/描述保持完整，项目优先使用已配置封面/图标作为分享图片。
