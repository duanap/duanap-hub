## 实施与验收

1. 本地独立用户、密码哈希、恢复密钥、可撤销会话；博客断网时注册、登录、资料仍可用。新模式同时要求 `HUB_LOCAL_ACCOUNTS_ENABLED=1` 与后台 `accounts` 模块开启；切换不自动复制生产用户、密码或旧身份会话。
2. 主域 QQ 使用自己的 AppID/AppKey 和既有 `/oauth/qq/callback`；服务端验证 state、一次性事务和返回的 client_id。自动获取昵称及 QQ 头像，高清缺失回退小图；头像来源可切换，后续 QQ 登录仅更新 QQ 来源头像。
3. 博客关联沿用现有 S256 授权，绑定意图锁定主站用户及发起会话。同一博客 UID 唯一关联一个主站用户；不按昵称、头像或邮箱合并。令牌失效需重新授权，主站会话不因此失效。
4. QQ 登录默认接续博客同 QQ 检查，登录入口说明该行为；不要求先填写用户名或密码。博客通过自己的 QQ 应用验证，仅发现已有 QQ 用户，不自动创建博客账号或给当前博客用户绑定新 QQ。两应用配置相同 UnionID 范围，且两端服务端获取的非空 UnionID 一致才关联；未找到、缺证明、身份不同、取消或冲突均保留主站登录和原有绑定并分别提示。两应用独立，可能需要额外一次博客 QQ 授权。手动博客授权本身不要求 QQ 相同，页面区分“已授权关联”与“已核验同一 QQ”。
5. 积分只读自博客；签到请求复用现有单次回执、事务与并发防重。未关联用户即使直接调用 API 也不能签到。解除关联撤销博客访问，不删除博客账号或账本。
6. 新的持久身份库必须独立备份与恢复；内容备份不应默默包含密码和关联身份。独立身份备份命令必须移除会话、授权事务和加密博客访问令牌，只保留不可逆密码/恢复密钥哈希及账户关联。身份恢复后清除普通会话、授权事务和博客访问令牌，关联标记保留并要求用户重新授权。正式切换前备份现有两站，先隔离验收，不覆盖原用户或积分。

## 边界与配置

主站独立账户使用现有 `HUB_ACCOUNTS_TOKEN_KEY`（长期保留，变更需单独密钥轮换设计）。主域 QQ 私有配置为 `HUB_QQ_APP_ID`、`HUB_QQ_APP_KEY`，不可填入博客 QQ 配置。`HUB_QQ_UNION_REALM` 与博客私有常量 `DUANAP_HUB_QQ_UNION_REALM` 仅在平台确认两个应用已打通后设置相同范围标识；这不是接口权限的替代物。

第一版使用用户名、密码和一次性交付的随机恢复密钥，不依赖尚未验收的邮件服务。恢复密钥以哈希存储；使用后失效并交付新密钥。QQ 创建的用户可在近期认证后设置密码并领取恢复密钥。实际邮件恢复仍需独立接入和送达验收。

QQ 创建的账号始终可直接 QQ 登录，自定义用户名与设置密码均可选。修改用户名不改变主站 UID、QQ 或博客映射；已设置密码时验证密码，纯 QQ 账号要求五分钟内验证过 QQ。用户名有唯一约束，修改撤销其他主站会话；QQ 更换/解绑仍要求密码与恢复密钥作为备用登录方式。

网络接口有限响应大小和超时，不重试换令牌请求；数据库唯一约束解决注册/绑定并发，事务同时检查用户、会话与已有映射。密码尝试持久限流、敏感操作同源与 CSRF 校验；普通会话不授予 Studio 权限。发布回退保留新身份库及密钥，不回写旧余额或替换 Studio 密码。

QQ 官方接口：[用户资料与头像](https://wiki.connect.qq.com/get_user_info)、[UnionID](https://wiki.connect.qq.com/unionid介绍)。真实 QQ、UnionID 权限和邮件送达不以合成验收替代。

## 私有账号备份与恢复

账号库 `members.sqlite` 不进入 Studio 下载的内容备份。停止应用后用 `node scripts/backup-members.mjs --data-dir DATA_DIR --output PRIVATE_PATH` 生成权限 `0600` 的独立快照。脚本移除会话、授权事务、限流记录及博客访问令牌；保存后应将其与现有私有备份一同放在受控离站存储中。不要上传到 Git、公开目录或发送至聊天。

恢复前停止应用，运行 `node scripts/restore-members.mjs --input PRIVATE_BACKUP --data-dir DATA_DIR --confirm-restore`。已有账号库会原子留存在同目录生成的私有回滚文件中；恢复拒绝符号链接、活跃应用锁、未知库结构和损坏文件。恢复会清除登录会话/授权事务并撤销博客访问令牌，博客 UID 关联仍保留，用户需要重新授权。主站内容恢复会保留独立主站账号与密码，只撤销会话和旧博客令牌；内容回滚文件同时保存账号库快照。两种回退都不会重置 Studio 管理员密码或重写博客账本。
