| --- | --- |

| 项目 / 工具 / SEO | 项目、版本、公告、路线图、人工运营状态；本地密码生成器；模块、导航、robots、Sitemap、RSS 联动 |

博客只读取公开摘要，完整文章和评论仍在 WordPress 管理。未移植参考站的私有服务或账号体系；首页没有指向未实现留言、赞助、植物生成或音乐搜索 API 的假按钮。

## 博客来源配置

1. 在服务器端 `.env.local` 设置 `HUB_CONTENT_WORDPRESS_URL=https://blog.duanap.cn/`，可包含 WordPress 安装子目录。它是可信部署配置，不接受浏览器提交的请求目标；不要填写账号、密码、查询串或 fragment。
2. 重启应用。在 Studio「主页资料」填写公开博客入口，启用博客动态模块，勾选「在博客页显示文章摘要」并保存，再点击「刷新文章摘要」。关闭博客动态模块会停止摘要服务；关闭博客页面模块或取消页面摘要勾选只隐藏该页摘要，原有首页/RSS遵循博客动态模块。
3. 只读请求使用 [WordPress Posts REST API](https://developer.wordpress.org/rest-api/reference/posts/)，每页100篇，最多5页；只索引已发布、非未来的条目。不会调用账户、积分或文章写接口。
4. 缓存位于 SQLite `content_cache` 表（与既有首页博客卡片/RSS共用）。公开访问每15分钟按需刷新；整轮请求/响应正文共用3.5秒期限，单页最多512,000字节，禁止跟随重定向。自动失败后一分钟内不重复请求；管理员可主动重试。失败保留上次摘要并显示来源、同步时间和降级提示。
5. 缓存是可重建的外部副本，随既有内容库进入备份，但不作为博客正文权威。未配置来源或关闭博客动态模块时不联网；博客页关闭时不由该页发起同步，首页/RSS遵循博客动态模块。首页、Studio、项目、相册、随记、友链和 SEO 均不 await WordPress。

真实来源本地联调：`https://blog.duanap.cn/` 的公开 API 返回200，本地应用实际同步1篇公开摘要，列表、标签、摘要详情和原文入口可用。没有修改生产博客。

## 验证结果

- `npm run typecheck`、`npm run build`、`npm run check:structural`：通过。
- Windows Edge，Next 生产模式：`HUB_TEST_SERVER_MODE=production`、`HUB_TEST_OFFLINE=1` 下 **62/62** 浏览器/API 用例通过。服务器拒绝真实外网 fetch，博客适配器仅通过测试专用保留域名夹具供给成功、503、无效 JSON、超大正文和超时；真实博客联调单独进行。
- `npm run test:backup`：**11/11**；`npm run test:env`：**1/1**。合计 **74项**，无跳过。新增浏览器用例实际下载在线归档，恢复到隔离目录，再恢复回滚归档，核对首页卡片、文案、歌单、博客开关完整保留，归档不含会话。
- 默认桌面卡片比例、自定义桌面/820px平板/390px手机布局；公开六页移动导航、图片灯箱、深浅主题、后台输入对比度检查通过。新增首页字段的旧高优先级白底问题先复现失败，再修正并保留回归测试。
- 数据仍为 schema 2。本批通过站点设置 JSON 添加配置，无新表、无依赖变化。旧设置自动补默认；旧应用不认识新键，回滚应使用匹配版本的设置/数据备份，不可直接复用新设置库。
- 预览复用上一批独立数据目录，原项目与媒体保留；启用真实博客摘要前已创建在线备份。本地访问端口1030，常规开发端口1026，测试端口1027。

## 使用与交付

新目录解压后按 README 安装依赖、生成独立管理员密码、填写 `.env.local` 并运行。源码包包括应用、资源、配置示例、锁文件、测试和说明；不包含本机 `.env.local`、数据库、媒体用户数据、管理员会话、node_modules 或 `.next`。既有静态HTML原型仍单独保留在 `prototypes/zyyo/`。

部署遵循 `DEPLOYMENT.md`；备份与停机恢复遵循 `BACKUP-RESTORE.md`。本次仅完成本地交付；正式域名、源站/EdgeOne、上线流量与搜索平台收录需在实际发布时另外验证。
