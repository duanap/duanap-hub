# P2-2 主站账号中心隔离验收

状态：隔离候选完成，生产未发布。真实 WordPress 7.1.3 + WP OAuth Server 4.5.2 + Bridge 0.1.0 已贯通；完整子比加载、QQ 授权、Redis 与正式回退仍待验收。所有测试使用全新库和合成用户，没有复制生产用户或积分。

## 当前能力

主站经博客授权登录，以 `hub_uid` 确认身份；账号中心显示头像/昵称、UID、权威积分、北京时间签到状态、近期流水和主站会话。修改资料、恢复密码和第三方绑定进入博客现有流程。当前没有签到写入按钮、积分发放或新的 QQ 注册流程。

WordPress 身份不能授予 Studio 权限。`hub_user_session` 与 `hub_admin_session` 的 Cookie、数据库和鉴权独立。

## 私有配置与默认关闭

同时满足服务器 `HUB_ACCOUNTS_ENABLED=1` 和 Studio 的 accounts 模块 enabled，账号路由与导航才参与。两者默认均关闭；缺失密钥/地址时账号 API 返回 503，不连接外部服务，也不影响 Core。

| 服务器变量 | 作用 |
| --- | --- |
| `HUB_WORDPRESS_URL` | 已验收的 WordPress HTTPS 基地址，可包含安装子目录 |
| `HUB_WORDPRESS_CLIENT_ID` | Bridge 保护的专用机密客户端 |
| `HUB_WORDPRESS_CLIENT_SECRET` | Provider 客户端密钥，仅服务器保存 |
| `HUB_ACCOUNTS_TOKEN_KEY` | 32 随机字节的 base64url 编码，43 字符；独立于 Studio 密码 |
| `HUB_SITE_URL` | 主站准确 HTTPS origin；回调固定为 `/api/auth/callback` |

Provider 客户端与 Bridge `DUANAP_HUB_REDIRECT_URI` 必须配置同一个完整回调。配置示例仅含空值，实际密钥保存在受控 `.env.local`，不得放在 NEXT_PUBLIC 变量或聊天中。

`HUB_ACCOUNTS_ALLOW_LOOPBACK=1` 仅用于主站和 WordPress **都为 127.0.0.1** 的夹具；不为公网地址放开 HTTP。HTTPS 保持证书验证，临时测试 CA 通过测试进程的信任配置加载，未关闭 TLS 验证或修改生产证书。

## 会话与数据边界

- 每个授权事务有独立 state、S256 verifier 和浏览器绑定 Cookie，5 分钟有效、只消费一次；首个双标签页并发也不覆盖绑定。共享浏览器标记仅辅助限制请求，事务标记完成后删除。
- 回跳仅允许 `/account` 下的站内路径，拒绝任意域名、路径跳转及重复参数。身份来自服务器访问的受保护本人 API。
- `accounts.sqlite` 按需独立打开；只保存哈希化会话/授权标记、加密令牌/verifier/身份及必要期限。AES-256-GCM 使用随机 IV 和上下文绑定，无会员密码或第二份积分余额。
- Cookie 为 HttpOnly、SameSite=Lax、Path=/，公网 Secure，不设置 Domain。会话最多 3600 秒，且不超过 Provider 实际期限；不接收 ID Token 或刷新令牌，过期重新授权。
- 改写接口同时验证精确 Origin 和当前会话的 CSRF nonce。撤销只能操作本人的会话；本地撤销先完成，上游撤销失败明确返回未确认，不阻止退出。
- 撤销立即删除服务端会话；共享用户 Cookie 不由迟到的退出/401 响应清除，避免误删另一个标签页的新登录。旧随机标记失去授权，只等待原到期时间自然清除，重放被拒绝。
- 业务数据不做本地缓存。每次读取核验权威身份；前端核对每张卡片的 subject，一致后发布私有快照，切换用户/失败时清空旧展示。
- WordPress 请求各自有 2.5 秒超时、64 KiB 响应上限，不跟随重定向，不在 SQLite 事务或 Core 内容队列内等待。错误不输出上游原文或凭据，不将失败显示成零余额。
- 配置/模块变更会使旧授权和会话失效；排序只改变布局，不能注销用户。生命周期戳严格递增，同毫秒关闭/重开也会生成不同授权代际；旧请求在写入/响应前复核当前配置。
- 授权请求按浏览器与全局容量限制；每个账号最多保留 16 个本地会话。过期标记/会话在账号请求时清理，冷站不承诺到点物理删除；停用保留私有数据供受控清理。

## API 与 SEO

登录/回调为 GET，退出为 POST：`/api/auth/login`、`/api/auth/callback`、`/api/auth/logout`。

本人 GET：`/api/account/me`、`points`、`checkin`、`points/history`、`sessions`；本人会话撤销为 `POST /api/account/sessions/{id}/revoke`。数据只按当前会话取得，不接受传入 UID/用户 ID/令牌覆盖。身份和流水额外字段白名单过滤。主站普通 Cookie 或令牌不能用于 Studio。

账号页面及 API 为 `private, no-store`、noindex，不加入 Sitemap/Feed；robots 已拒绝 `/account` 和 API。账号数据库异常仅使账号操作不可用。

## 恢复与下一批

内容备份不包含 `accounts.sqlite` 或凭据。离线恢复在既有维护/进程锁及路径检查下清除账号文件及 WAL/SHM，恢复/回退后普通用户必须重新授权；不把旧身份会话放入回滚归档，不用旧 WordPress 积分快照覆盖新交易。

正式启用前仍需完整主题登录界面、QQ 真授权、Redis、Nginx/EdgeOne 私有缓存和生产备份/回退验收。特别核对反代 Host/HTTPS，不能让 Provider 返回未经处理的规范化跳转。下一批 P2-3 处理原生绑定唯一性、冲突与恢复；P2-4 再实现原生/主站统一签到与事件幂等，本批不给它们写已完成。
