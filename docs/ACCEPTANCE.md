# P1 验收清单

本地开发候选 0.2.0，2026-10-11。实际命令、范围和限制见 P1-VALIDATION.md。

## 本地已验证

- [x] 固定依赖安装、类型生成/检查、生产构建及结构语法检查。
- [x] 20 项回归、16 项真实浏览器测试、13 个生产构建路由与 SSR 冷启动。
- [x] 首页/about/projects/games/tools、已发布详情、robots、Sitemap、RSS 和分享图。
- [x] Studio 独立管理员登录、权限/Origin、项目发布与记录编辑、模块/工具启停。
- [x] 发布状态与手工运营状态分离；维护保留详情，普通公告不误报维护。
- [x] 草稿不公开；旧 slug 只对已发布项目重定向；未来公告不挤掉有效动态。
- [x] 桌面、平板、常见手机宽度无横向溢出，五项导航、抽屉和截图键盘操作。
- [x] 未保存提示、导航保护、同标签页草稿恢复，保存失败不假报成功。
- [x] 客户端工具真实输入与隐私边界；未实现工具明确待完善。
- [x] 媒体格式、大小与图片内容验证，真实上传和 WebP 读取。
- [x] 旧 Hub v0 数据升级保留内容和原始快照，新版 schema 拒绝旧代码 DDL。
- [x] WAL 安全备份、媒体清单、备份下载、新目录恢复、损坏拒绝、失败临时目录清理。
- [x] 无第三方配置可启动，关闭可选模块 Core/Studio/SEO 继续可用。
- [x] 独立代码审查的重要问题已通过回归修复。
- [x] 部署、数据目录和回滚步骤已提供；没有 CI/Docker 前置条件。
