# 验收清单与故障隔离演练

## A. 本开发包的结构级检查

- [x] 新项目完全独立于旧生产仓库，Git 私有目录与忽略规则已配置。
- [x] P1/P2/P3 范围明确，第三方 API 不是 P1 启动依赖。
- [x] 目录/环境变量与 README 一致，包含模块注册、公开页面、Studio 骨架、SQLite 模型、robots/sitemap/feed。
- [x] 在联网开发环境中 `npm install`、`npm run typecheck`、`npm run build` 均成功（2026-10-13）。
- [ ] 浏览器/移动端与管理员真实操作测试通过。

## B. P1 上线门槛

- [ ] 主页/about/projects/games/tools 和已发布项目详情均正常响应。
- [ ] Studio 登录/登出、编辑资料、创建/编辑/下架项目、管理公告、模块排序与启停通过。
- [ ] 项目运营状态由人工填写；维护中不删除已发布项目或强制下线详情页。
- [ ] 公告区分日志、更新预告、维护公告、路线图；草稿不展示、不进 RSS。
- [ ] Sitemap 只含允许收录的已发布页面；robots、安全路由和 canonical 符合预期。
- [ ] 备份恢复、移动端、搜索引擎抓取与 EdgeOne 缓存验证通过。
- [ ] WordPress/EdgeOne/小游戏均断网，公开页面、后台、静态资源仍能访问。
- [ ] 禁用任意可选模块不导致导航死链或 500。
- [ ] 从旧主站迁移有明确备份与回滚演练证据。

## C. P2 验收

- [ ] QQ 首次登录创建 WordPress 用户并分配唯一 `hub_uid`；重复登录不会重复注册。
- [ ] GitHub/Gitee 绑定到同一个 `hub_uid`；冲突不被昵称/头像误合并。
- [ ] 主站和博客共享积分；同一自然日并发签到和重复调用仅发放一次。
- [ ] WordPress 停机时公开主页正常；积分写入拒绝或排队且有显式状态。
- [ ] 普通用户无法访问 Studio 管理员 API。

## D. P3 验收

- [ ] Hearts/mhsp/mj-dual 原有游客和重连保持有效，老数据可安全认领。
- [ ] QQ 机器人绑定后，共享同一修仙角色和签到状态。
- [ ] EdgeOne、博客文章、GitHub 其中任一接口超时不影响其他 Widget 和 Core。
- [ ] IP 查询、密码生成、文档转换无明显 SSRF、隐私外传和超大文件风险。
- [ ] 模块独立维护、缓存降级与最近同步时间标注通过。
