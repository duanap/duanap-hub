# Notes、友链与音频上传 · 本地验收

本轮按用户要求实现，尚未替换正式站。没有修改任何生产文案、发布标记或上传文件。

## 使用

- Notes 没有仅显示2条的限制。只展示已公开且到发布时间的文案，每页18条；草稿不自动公开。后台显示公开/草稿/排期数量，保存提示明确区分状态，并提供“立即发布”。
- Notes 卡片使用等高网格，正文按浏览器实际排版预览四行；超过四行才出现“展开”，点击打开完整卡片。支持长文滚动、常驻关闭按钮、背景关闭、Escape和焦点返回；字体或宽度变化会重新判断。
- 友链填写地址后点击“获取网站名称和图标”，结果先填入当前表单，保存后生效。失败时手工内容保持可编辑。可选择已有分类，也可输入新分类。
- 歌曲库可上传MP3/M4A/WAV/OGG/FLAC容器文件（单文件20 MiB），自动填入本站音频地址，空标题从文件名填入；保存歌曲库后用于全站播放器。也可继续使用音频直链。文件不转码，编码仍需浏览器支持。
- 媒体库可预览/删除音频，图片选择器仅显示图片；即使歌曲下架，只要库中仍引用该文件，就不能误删。

## 验收

类型检查、生产构建和结构检查通过。39项生产模式浏览器/API用例通过，包含14项新增场景：多条及分页、草稿/排期/立即发布、等高/四行/全文弹窗/手机、分类复用/获取成功与失败、公开地址与逐跳跳转/DNS固定、文件上传/鉴权/大小/Range/HEAD、WAV/MP3真实解码与进度控制、音频归档与实际恢复回滚。另有13项备份格式/恢复和1项环境检查通过。

```powershell
$env:HUB_TEST_SERVER_MODE='production'
$env:HUB_TEST_PORT='1037'
npm run test:replica
```

验收端口可配置以隔离本机已有服务。另在独立预览中检查桌面与390px手机、等高卡片和全文弹窗、歌曲文件上传、已有分类与真实公开网站信息获取；客户端错误0。演示内容与临时登录不进入Git或源码包。

网站获取仅管理员可触发；限定公开HTTP(S)标准端口，每个DNS答案及重定向目标均检查，固定已检查地址建立连接，保留TLS验证，无Cookie/授权转发。整条流程限5秒、最多3次跳转、HTML限256 KiB，只解析页面信息，不执行网页脚本。获取失败可手工填写。

音频以文件头/容器结构检测，随机文件名、受控目录保存，公开响应支持Range/HEAD和nosniff，流式读取。文件随在线备份及离线恢复/回滚保留；包含音频的新归档显式version 2，旧图片归档继续可读，具体限制见 [备份与恢复](BACKUP-RESTORE.md)。没有新增npm依赖。

## 发布前

正式Nginx当前上传限制为6 MiB。发布这版时需备份配置，将本域限制调为22 MiB，执行语法检查再reload，随后经公网验收上传。示例配置已更新；当前线上配置未改。

生产替换须按仓库AGENTS.md对本版本确认。后续继续本机Linux构建、服务器只导入产物和运行；保留匹配的数据/媒体与代码回退材料，不在生产服务器编译。旧运行代码不支持新的音频归档，回退必须匹配旧备份。第三方网站可能拒绝获取、没有图标或使用浏览器不支持的音频编码，不保证任意网站和编码都可用。
