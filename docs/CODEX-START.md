# 发给 Codex 的第一次开发任务

请将本仓库作为独立新项目开发，先完整阅读根目录 `AGENTS.md`、`docs/ROADMAP-V1.1.md`、`docs/ARCHITECTURE.md`、`docs/REQUIREMENTS-V1.0.md` 和 `docs/ACCEPTANCE.md`。

**本轮只开发 P1。** 第一目标是让个人主页、独立项目详情、项目的人工状态/版本/更新日志、现代化 duanap Studio、模块启停与 SEO 构成一个可实际使用、可独立上线的成品。暂不接入 QQ OAuth、WordPress 用户与积分、QQ 机器人、游戏战绩、EdgeOne 或博客文章。

工作要求：

1. 先执行本地依赖安装、类型检查与构建，修复 starter 的错误并列出验证证据。
2. 阅读 `duanap/duanap-index` 和 `duanap/index` 现有代码，借鉴可复用能力但不覆盖旧仓库。读取生产数据只用于只读审计，真正迁移需单独授权。
3. 先把后台重新设计：精简分组侧栏、卡片式项目管理、全宽编辑页、按需预览，统一浅色/深色和移动端响应式。
4. 项目内容增加完整字段、Markdown、图片、版本日志、预更新思路、维护公告及路线图，内容与运营状态分离。
5. 完成首页编排、模块启停/排序、安全后台登录、SEO、robots、Sitemap、RSS、基础工具和数据备份。
6. 做完整的本地访问与操作验收、扩展 API 故障模拟和回滚准备。每次修改输出简短的改动摘要与测试结果。

技术纪律：KISS、避免过度工程化、无 Docker、无强制 CI 和 GitHub Actions。以当前阶段目标为准，先保证主站可以上线，其他模块以后再接入。
