# 独立复刻范围 · 2026-10-21

用户纠正产品方向：先复刻 https://zyyo.net/，作为独立新项目提供后台管理。原有“项目门户兼容 P1/P2/P3”不再决定本轮页面、内容来源和验收；历史文档和代码不等于新产品默认功能。

| 页面/区域 | 内容权威 | 验收行为 |
| --- | --- | --- |
| 首页 | 站点设置、已发布相册或单独挑选的首页图片 | 原默认卡片位置；文字、兴趣标签、图片、图标及卡片顺序/宽度/显示可编辑；不追加项目、游戏、工具区块 |
| Notes | 管理员添加的文案 | 正文、可选标题、配图、草稿/立即发布/排期、排序、搜索、随机和分页；等高卡片，超过实际四行弹窗展开；不合并项目更新 |
| Photos | 独立相册与照片 | 相册标题、简介、封面、照片上传/批量上传、说明、排序、发布；公开相册、照片与灯箱；不读取项目图片；封面不是自动新增的照片 |
| Links | 管理员添加的友链 | 名称、分组、地址、介绍和自定义图标；可获取网站名称/图标，选择已有分类或新建；不自动生成项目或个人社交链接 |
| 音乐 | 管理员歌曲库 | 上传音频（最大20MiB）或使用直链，标题、歌手、封面、排序、上架/下架；搜索选曲、实际播放、进度、音量、循环/随机、错误重试；跨公开页面导航继续播放，不自动播放 |
| 图标 | 站点及社交设置 | 上传图片、媒体库或 HTTP(S) 图片；支持站点标志/导航/社交/音乐/RSS，保留原色，空值使用内置图标 |

参考原站的首页卡片、照片叠片、文案卡片、图标导航和音乐抽屉；文案等高与四行弹窗按用户最新要求执行。后台管理是本项目新增能力。干净数据库不导入原作者内容、旧站项目、歌曲或测试记录，内容为空时保持相应空态。

安全与运维约束继续适用：Studio 独立鉴权、写入来源校验、数据在受控目录、内容与媒体一致性备份、可恢复；不自动操作生产数据或登录第三方账号。本轮不要求会员/积分/游戏/EdgeOne 等旧需求通过兼容验收。

本轮在独立本地目录验收；先形成可审查源码和测试结果，再决定是否发布。旧发布与私有备份保留。
