# P3：EdgeOne 只读统计

接入首页卡片与 Studio“EdgeOne 数据”：按允许域名选择汇总范围、24 小时或 7 天、标题/说明，沿用首页模块启停、排序和区域尺寸。默认关闭；用户本轮选择先部署，长期只读凭据稍后配置。电脑上的腾讯云临时授权不复制到服务器。

## 指标与运行边界

固定访问腾讯云国内端点 `https://teo.tencentcloudapi.com/`，API 为 `DescribeTimingL7AnalysisData` / `2022-09-01`，TC3 签名，无新增依赖。始终指定单个 ZoneId、精确域名和 `mitigatedByWebSecurity` 条件；不查询客户端 IP、URL、安全事件详情或账号全站数据，不修改 EdgeOne 配置。

- 请求量：所有请求，包括 Web 防护缓释；不是 UV/PV。
- 响应流量：同一筛选范围的 EdgeOne 响应字节数，1000 进制单位。
- 缓存命中率：正常响应中 `hit / (hit + miss)` 的请求比例，排除 dynamic/other；不是流量命中率，也不冒充控制台其他口径。
- Web 防护缓释请求：被拦截或挑战的请求，不是攻击事件数。API 空结果、缺失指标或无有效明细显示“暂无数据”，只有明确返回的零显示 0。

四组查询共用一个 5 秒时限，响应各限 256 KB，拒绝重定向。时间范围采用当前至少 15 分钟以前的完整 UTC 小时，页面以北京时间标注实际起止时间；API 实测要求不带毫秒的 RFC3339 参数。首页 SSR 只读本地缓存，浏览器单独请求统计；缓存 30 分钟，失败自动退避至少 5 分钟，手动同步至少间隔 30 秒，并发刷新合并。失败保留整组上次成功数据及其时间窗口；模块代次/配置变化阻止旧结果写回。

新增 `edgeone_settings`、`edgeone_cache` 独立表，库版本保持 1，旧设置 JSON 不扩展。内容备份包含汇总缓存和展示设置，不包含凭据；旧发布忽略新表，回退无需回写内容库、会员库或博客账本。

## 服务器配置

1. 在腾讯云 CAM 创建或选择专用子账号，授予 `teo:DescribeTimingL7AnalysisData` 对站点 `zone-3r3b3jw2cw0l` 的读取权限。通过策略生成器指定该站点，避免管理员权限或全部站点 `*`。本轮未创建账号、密钥或权限策略。
2. 在服务器私下保存 `/www/wwwroot/duanap-hub/shared/edgeone-readonly.json`，内容格式如下；不要把实际值发送到聊天或 Git：

   ```json
   {"secretId":"实际 SecretId","secretKey":"实际 SecretKey"}
   ```

   文件所有者 `root:www`、权限 `0640`，父目录须允许 www 遍历，文件不能允许其他用户读取。也支持带 `token`、Unix 秒 `expiresAt` 的 STS 文件，但必须由独立安全机制刷新；应用不创建或续期云凭据，不接受 tccli 的 OAuth 刷新凭据。
3. 发布配置在服务器 `.env.local` 预留：

   ```dotenv
   HUB_EDGEONE_CREDENTIAL_FILE=/www/wwwroot/duanap-hub/shared/edgeone-readonly.json
   HUB_EDGEONE_ZONE_ID=zone-3r3b3jw2cw0l
   HUB_EDGEONE_DOMAINS=duanap.cn,www.duanap.cn,blog.duanap.cn
   ```

4. 凭据文件可原位原子替换，无需重新构建；在 Studio → EdgeOne 数据确认读取状态、选择公开域名、保存、启用，再点“立即同步 EdgeOne”。若修改环境变量则重启 `duanap-hub.service`。此开关会公开所选域名的汇总指标，默认只选主域和 www。

本轮已使用现有临时授权只读查询真实免费套餐站点，并用实际应用签名适配器复核请求、响应流量、缓存 hit/hit+miss 与安全缓释条件；安全缓释空结果保留 null。临时凭据不进入发布包、缓存、截图或服务器。

本地隔离用例覆盖签名、域名限制、明确零与空数据、拒绝授权、无效数值、超大响应、重定向、慢请求、成功缓存保留、并发合并与禁用/重启代次、Core/SEO 可用、后台权限与 CSRF、草稿提醒、7 天窗口、移动端和不含密钥的备份。生产长期凭据与最终自动同步需配置后另验，部署本身不代表该项已完成。
