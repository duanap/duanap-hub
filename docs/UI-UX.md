# 前台与 duanap Studio 界面设计规范

## 风格

「优雅、小而美」：浅灰背景、白色低对比卡片、少量蓝色强调；明暗主题可选。使用中性字体；卡片圆角 16–20px，间隔约 16px；控件高度约 40–44px。允许轻微状态反馈，尊重 `prefers-reduced-motion`。

## 首页

头像/昵称/简介 + 个人资料 + 项目精选 + 游戏入口 + 可用工具 + 已发布动态 + 备案。模块可启停、排序。内容来自服务器渲染，不能依赖客户端加载才有关键 SEO 正文。博客 P3 接入，不因未接入而展示假的文章或指标。

## Studio

- 左侧约 220px 分组导航，可折叠为图标栏；内容区优先全宽且限制最大阅读宽度。
- 不采用每页固定「编辑区 + 右侧预览」布局；仅在主题/首页编排等场景按需预览。
- 项目/工具/游戏采用卡片网格；访客日志/用户列表/备份采用可排序表格；属性编辑用独立卡片或独立详情页。
- 设置页的备案信息必须采用 ICP/公安备案两张卡片；SEO/搜索引擎/RSS 各自独立卡片。
- 重要操作先确认，删除要显式提示；网络异常可重试；未保存修改有提示；不要提交成功前显示“已保存”。

## 数据卡片

EdgeOne、GitHub、WordPress、游戏作为扩展 Widget。每个卡片必须显示统计口径、时间段、来源、数据新鲜度和异常状态；未连接显示 `— / 未配置`，不虚构线上数据。EdgeOne 请求数不得称作 UV/PV。

## 响应式

桌面优先 3 列项目卡片，中尺寸 2 列，手机 1 列；导航在手机改抽屉或紧凑入口，表格滚动与触摸友好。
